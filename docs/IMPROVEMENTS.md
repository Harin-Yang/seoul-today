# 써보면서 찾은 개선점

직접 써보며(성수·홍대·강남·광화문 위치, 360×640~390×844 화면, 라이트/다크) 발견한 문제와 처리 결과.

## 1차 (2026-10-09)

### 데이터
| 발견한 문제 | 처리 |
|---|---|
| 교육/체험 110건 중 상당수가 놀러 갈 수 없는 행사 (청소년 단체 교실, 경력자 아카데미, 도서관 북큐레이션, 일자리박람회, 모집 공고) | ✅ 제목·대상 규칙으로 제외 (`classify.mjs`의 `NOT_OUTING_*`, `RESTRICTED_TARGET`) |
| 종료일이 2626년인 오타 데이터 | ✅ 3년 넘게 남은 행사는 날짜 오류로 제외 |
| 같은 행사의 1일차·2일차가 따로 표시 | ✅ 같은 장소의 회차를 하나로 묶음 |
| 라벨이 혼놀에 쏠림(242/327), 지도 핀이 거의 보라색 | ✅ 저녁 공연은 데이트 가산, 동점이면 친구와>데이트>혼놀 순으로 대표 라벨 분산 |
| 서울시 데이터가 얇음: 19,596건 중 2주 내 진행은 약 430건 → 홍대 0곳, 강남 1곳 | ✅ 자동 줌(주변 8곳 이상 보이게), ✅ 소스 추가(문화정보원·관광공사, 키 활성화 대기) |
| GitHub 러너에서 서울시 API 연결 시간 초과로 수집 전체 실패 | ✅ 재시도 확대, 소스별 직전 데이터 재사용, 워크플로 단계 재시도 |
| 월요일 휴관 미술관이 월요일에도 추천됨 | ✅ 운영시간 문장에서 정기 휴관 요일 추출 → 오늘/주말 휴관이면 숨김 |

### 화면
| 발견한 문제 | 처리 |
|---|---|
| 핀이 라벨 이모지뿐이라 무슨 행사인지 모름 | ✅ 핀 아이콘 = 카테고리(🎨🎤🎭🎪…), 색 = 라벨 |
| 목록에서 이미 하는 중인지, 나중에 시작하는지 구분 안 됨 | ✅ "10.12 시작 / 오늘까지 / ~10.28", 도보 N분 |
| 상세에서 무슨 행사인지 설명이 없음 | ✅ 행사 소개문, 예매·신청 링크, 네이버지도 |
| 폰 뒤로가기를 누르면 앱이 닫힘 | ✅ 상세 열 때 history 기록 → 뒤로가기 = 목록으로 |
| 친구·애인에게 보내기 어려움 | ✅ 공유 버튼 + 공유 링크(`?e=id`)로 바로 그 행사 열기 |
| 지도를 눌러도 시트가 안 내려감 | ✅ 지도 탭 → 시트 내리기/상세 닫기 |
| OpenStreetMap 저작권 표기가 시트에 가려짐 | ✅ 시트 위로 올림 |
| 상세에서 선택한 핀이 시트에 가려짐 | ✅ 시트 위 영역 가운데로 지도 이동 |
| 퇴근 후 갈 곳을 찾기 어려움 | ✅ 🌙 저녁 필터(19시 이후 운영) |
| 비 오는 날 야외 행사가 섞임 | ✅ 날씨 표시(Open-Meteo), 비 50% 이상이면 "실내만" 칩 강조 |
| 특정 행사를 찾을 수 없음 | ✅ 검색(2주 전체, 결과로 지도 이동) |
| 하나 보고 나서 근처에 또 갈 곳? | ✅ 상세에 "근처에서 같이 가기 좋은 곳" (도보 15분 내 3곳) |
| iOS 홈 화면 아이콘이 깨짐(SVG 미지원) | ✅ PNG 아이콘 |
